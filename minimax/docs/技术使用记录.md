## seekdb（实测）

- 包：`@oceanbase/seekdb-node@1.4.0` + `@oceanbase/seekdb-node-darwin-arm64@1.4.0`
- `SELECT VERSION()` → `5.7.25-OceanBase seekdb-v1.4.0.0`
- `@@version_comment` → `OceanBase 4.3.5.3 seekdb (r1.4.0.0) (Built ... Sep 21 2026)`
- 端点：Unix socket（`connectionOptions().transport = unix_socket`），未占用固定 TCP 端口
- 建表：`specs` / `code_chunks` / `test_cases`，均含 `VECTOR(384)`
- 写入：`specs=2`、`code_chunks=5`、`test_cases=3`
- 向量检索：`cosine_distance(vec, ?)` 排序返回，示例距离 `0` 与 `1`，Top-2 正确命中
- 复现：`node cli.mjs ingest`（首次启动较慢）
